# My Daily Devotion

My Daily Devotion (MDD) is a private, local-first Christian devotional application built around four durable concerns: Scripture, personal response, prayer, and remembered spiritual history.

## Product definition

> Read Scripture. Respond when something matters. Pray intentionally. Let MDD remember the story.

MDD is intentionally not a social network, content feed, habit game, or general-purpose Bible study suite.
