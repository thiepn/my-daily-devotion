# Check a backup — read-only reassurance

This Batch D slice adds `/data/check`, reached through Your data's Backups section. It checks a retained `.mddbackup` without preparing or committing a restore. File bytes, passwords and decrypted records remain in memory; the screen returns only validated metadata and live/deletion-marker counts.

File-header inspection is provisional. Full validation reuses the existing bounded archive reader, checksums, encryption/password rules, schema and relationship validation in a temporary database that is always cleaned up. The result has no restore candidate or commitment capability. Historical plain and encrypted portable-v1 archives remain supported.

The screen uses the approved journal shell, botanical accent, warm surfaces, mobile navigation and shared record-count presentation. Six familiar content totals lead; detailed records and retained deletion markers remain available in a disclosure. Validation does not prove that a file is retained elsewhere or provide recovery of forgotten passwords.

Duplicate submissions are locked. Cancellation, input changes and leaving invalidate stale work; cancellation and success clear staged bytes and passwords. Optional browser-storage information is not required. Returning to Your data restores the complete originating URL, disclosure, focus and scroll position without exposing file content in navigation state.

Verification includes plain/encrypted checks, wrong passwords, corrupt bodies, accurate counts, zero-write snapshots, contextual return, narrow dark/enlarged text, and deterministic rendered comparisons. Exact-commit hosted certification and manual/device release gates are recorded separately in the draft PR. Supporting checks alone do not certify the complete offline product.

Compatibility remains physical database schema 2, domain contract 1 and ordinary portable backup format/schema 1. No recovery migration, account integration, reminder or new devotional event is introduced. Saved versions/removal recovery still require review of the schema-3 specification.
