# Morning Grace usability review

Status: protocol prepared; participant testing has not been performed.

Recruit six to eight willing participants spanning first-time and experienced devotional readers, including older readers. Include people who actually use screen readers or enlarged text; simulation does not replace their experience. Use synthetic writing and a disposable installation. Do not collect anyone's personal devotional content.

Run an uncoached 30–45 minute session on their ordinary device. Ask participants to think aloud; record consented observations and task outcomes, not religious judgments. Provide help only after noting where it was required.

1. Start without a plan. Find Scripture and create a prayer. Explain where the data is saved.
2. Explain calendar versus self-paced enrollment in their own words, then choose one and read today's passage.
3. Change reading appearance, select a Scripture range, write a reflection and bring it into prayer. Return to the original passage.
4. Add encouragement, record an answer, run a focused session and pause. Find the same prayer again through People or Search.
5. Revisit a selected History entry and its source. Explain the overview totals; check that no streak or spiritual score is inferred.
6. Create an encrypted backup, validate it without restoring, then restore into a separate disposable installation. Explain forgotten-password and browser-storage limitations.
7. Open a previously loaded app offline, read bundled Scripture, and find saved writing. Make an unsaved edit, navigate away, and explain save/discard consequences.

For assistive technology, also inspect landmarks, heading order, status announcements, disclosure state, dialog focus/trap/return, selected-entry focus and full Scripture ranges. For enlarged text and older readers, inspect line spacing, contrast, target size and comprehension. On physical phones, inspect keyboard-visible actions, safe areas, rotation and Back navigation.

Record device, browser/OS, assistive technology, task success without help, observed errors, recovery, participant wording, and severity. Judge read comfort, successful preservation/recovery, accurate action understanding and findability; do not optimize time spent or spiritual activity counts. Do not treat task speed as a devotional score.

Release gate: resolve blocking data-loss, misleading action, inaccessible navigation, unreadable writing, or failed recovery findings, then repeat affected tasks. Publish only anonymized technical findings. A passing automated suite does not close this gate.
