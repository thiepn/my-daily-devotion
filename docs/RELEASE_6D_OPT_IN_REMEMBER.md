# Optional remembering and backup reminders

On this day and monthly backup reminders start off. Your data → Privacy offers explicit activation and disable controls. Small typed browser-local choices and date-only dismissals are separate from the devotional database and portable backups. Browsing never creates activity, seeds preferences or enables notifications.

On this day uses exact stored month/day matches in earlier years, limited to reflections, answers, encouragement and highlights. Missing leap-day anniversaries are omitted, not moved. The existing History resolver excludes unavailable/tombstoned sources. The suggestion carries no private excerpt; its dedicated view reveals twenty available entries initially, then twenty more, with precise selected-Day destinations and contextual returns. Dismissal lasts the current local date.

Monthly reminders first become eligible one calendar month after activation. Month-end dates clamp to the next month's actual last day. A later browser backup-generation receipt postpones the reminder; it is never evidence that a file exists elsewhere. Remind me next month and disabling remain explicit. There are no scheduled browser notifications or network services.

Preference failures retain the actual saved choice and report failure without claiming protection. Foreground, local-date and storage changes refresh presentation. Optional suggestion failures do not replace usable Today or History content. Suggestions sit below the established compositions, preserving the default reference family.

Verification covers opt-in defaults, contextual source returns, dismissal/reload, defer/receipt/disable, storage failure, exact earlier-year dates, leap-day omission, tombstones, full database snapshots proving zero writes, narrow dark enlarged-text accessibility and six-width screenshots. Existing default Today/History screenshots remain unchanged; the expanded Privacy view deliberately grows. Hosted certification, human usability and physical-device review are separate gates.

Compatibility: physical schema 2, domain contract 1, ordinary portable format/schema 1. No new database stores, History events, sync or accounts. Schema-3 recovery remains gated by review of PR #31.
