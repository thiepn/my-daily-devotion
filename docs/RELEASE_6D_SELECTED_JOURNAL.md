# Selected-period journal copies

`/history/export` extends manual weekly/date-range browsing with explicit content choices, a complete readable preview, a selected Markdown download and browser printing/Save as PDF. This is separate from portable backups: there is no `data.json`, restore capability, draft payload, person notes, administrative settings or browser receipt.

The inclusive range uses stored devotional dates, not timestamp conversion. Current saved writing is resolved through the existing parent/child tombstone-aware History resolver. Missing/removed details are omitted and counted honestly. Reflections, prayer requests, updates/encouragement, answers and reading/highlight references are selectable. Ordinary prayed actions are not writing exports. This selects recorded History sources; it does not claim to export saved records that lack a corresponding historical event.

Text is complete, without the History excerpt limit or a 200-entry cutoff. Duplicate events about the same writing do not repeat its current text; recorded answer resolution identity remains distinct. Optional Scripture metadata failure leaves personal writing available, with canonical reference identifiers as a fallback.

The journal preview renders supported Markdown safely, skipping raw HTML and remote images. Selected Markdown preserves writing literally inside dynamically sized fenced blocks, preventing user-written HTML/images from executing in a viewer. Both reading copies are unencrypted. Download/print wording describes a request, never proof that a file was retained.

Print styles remove app navigation, controls and source actions, use a white paper canvas, literary typography, page margins, heading-aware breaks and paragraph widow/orphan rules. Browser pagination/PDF output is still browser-dependent; there is no separate PDF service. Preview source links preserve the complete selection and originating History return through the selected Day entry.

Supporting coverage includes >200 entries, inclusive dates, optional assets, removed sources, complete text, zero writes, section toggles, safe Markdown, download identity, print media, contextual returns, dark/narrow 200% reflow and six-width rendered comparisons. Manual review corrected inherited editor minimum-height whitespace and immediate URL-backed checkbox feedback. Exact-commit hosted evidence and physical-device/human usability gates are reported separately.

Compatibility remains physical schema 2, domain contract 1, ordinary portable format/schema 1. No new persistent stores, events or automatic suggestions. Schema-3 recovery remains specification-gated; accounts/sync remain outside this offline slice.
