# My Daily Devotion 1.3.0 — Morning Grace integration

This candidate combines the illustrated devotional journal releases into one reviewed change against main. It is not deployed automatically.

## Included work

- Today and Bible follow the canonical phone compositions with offline artwork, real BSB/M’Cheyne context, reader appearance controls and close verse-number spacing.
- The approved cream/forest app icon replaces the previous identity.
- Prayer includes filters, person identities, read-only upcoming-session previews and explicit session entry.
- History includes factual period metrics, grouped activity, calendar browsing, selected Day entries and Moments.
- Reflection and prayer capture preserve contextual handoffs and explicit saves; Detail/Settings/Focused Prayer retain revision-safe lifecycle actions.
- People/Categories provide searchable directories, linked requests and explicit starter-category creation.
- Data & Backup leads with encrypted export and reviewed, snapshot-bound atomic restoration. Download requests are not claimed as retained files.
- Certification builds once and checks the same files across eight browser shards and Windows image comparisons. Aggregation rejects missing/duplicate/stale evidence, retries and artifact changes.
- Deployment and publication are separate manual actions using a successful certification for the selected main commit. The certified ZIP is reopened and checked without rebuilding.

## Compatibility

Schema v1 and backup format v1 remain unchanged. UUIDs, revisions/tombstones, Scripture identity, prayer scheduling/queue semantics, stored devotional dates, explicit completion/prayed actions and offline assets remain covered by the existing suites.

Unsaved writing remains memory-only. Accounts, sync, migrations, native apps and reminders are later roadmap releases. Search, Collections and Reading Plan retain earlier compositions.

## Remaining fidelity and certification limits

The supplied board is the visual target. Current Caslon letterforms and authored/generated landscape crops are close to its family but not pixel-identical. Dedicated evening artwork remains later work. New journal screens have reviewed evidence, while Search/Collections/Reading Plan still need that composition.

Automated browsers do not certify physical-device keyboards or human screen-reader use. No origin transfer, cloud service, account, migration or deployment occurs in this integration.
